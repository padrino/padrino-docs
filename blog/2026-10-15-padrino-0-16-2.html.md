Padrino 0.16.2 is a maintenance release for apps that stay on 0.16 for now, such as Middleman sites, which require padrino-helpers below 0.17. It comes out alongside [Padrino 0.17.0](/blog/padrino-0-17-0/) and has nothing else from 0.17.

## Changes

- **HAML 6 and 7.** Block helpers such as `link_to ... do`, `content_for`, `form_tag` and nested layouts no longer fail with `undefined method 'block_is_haml?'` in HAML 6 and 7 templates ([#2317](https://github.com/padrino/padrino-framework/pull/2317), `@achiurizo`; reported in [#2322](https://github.com/padrino/padrino-framework/issues/2322) by `@kenchan`).
- **Ruby 4.0.** padrino-core now depends on the `ostruct` gem, which Ruby 4.0 no longer installs as a default gem; without it, a 0.16.1 app doesn't boot under Bundler on Ruby 4.0. On Ruby 4.0, `padrino console` also tells you to add `gem 'irb'` to your Gemfile instead of failing with a LoadError.

## Upgrading from 0.16.1

1. Run `bundle update padrino` (in a Middleman site, `bundle update padrino-helpers`). If your Gemfile pins `0.16.1`, change it to `~> 0.16.2` first.
2. On Ruby 4.0, add `gem 'irb'` to your Gemfile if you use `padrino console`.
3. Ruby 4.0 comes with Bundler 4, which removed `bundle --binstubs`. If Padrino 0.16 asks you to run it, use `bundle binstubs --all` instead, or run commands with `bundle exec padrino`. Padrino 0.17 gives the new instruction itself.

Nothing else changes: Ruby 2.7.8 or later, Sinatra 4 and Rack 3 are still required.
